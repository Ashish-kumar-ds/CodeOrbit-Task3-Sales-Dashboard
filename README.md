# CodeOrbit Tech – Task 3: Sales Dashboard

## Objective
Create an interactive sales dashboard in Microsoft Power BI to summarize revenue, order count, units sold, and sales performance by product, category, region, and date.

## Files in this repository
- `sales_dashboard_dataset.csv` — small illustrative dataset for practice.
- `dashboard_build_guide.md` — step-by-step dashboard build instructions and suggested visuals.
- `DAX_measures.txt` — suggested DAX measures for Power BI.

## Important
The CSV is a **sample dataset for demonstration**, not an official dataset supplied by CodeOrbit Tech. If the internship provided a dataset, use that official dataset instead.

## Build the Power BI dashboard
1. Install/open Microsoft Power BI Desktop.
2. Select **Home → Get data → Text/CSV** and import `sales_dashboard_dataset.csv`.
3. Confirm data types: Date = Date, Quantity = Whole number, Unit_Price and Revenue = numeric.
4. In **Modeling → New measure**, add the measures listed in `DAX_measures.txt`.
5. Add KPI cards for Total Revenue, Total Orders, Units Sold, and Average Order Value.
6. Add a bar chart for Revenue by Product, a chart for Revenue by Region, a donut chart for Revenue by Category, and a line chart for Revenue by Date.
7. Add slicers for Date, Region, and Category.
8. Format titles, currency, labels, and layout.
9. Save the finished Power BI file as `Sales_Dashboard.pbix`.

## Final submission
The `.pbix` file must be created and saved in Power BI Desktop. This GitHub repository contains the data and build guide; the actual Power BI file is not automatically generated by GitHub.
